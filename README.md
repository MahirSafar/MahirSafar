# 🚀 Current Focus — CommerceCore

<div align="center">

<a href="https://github.com/MahirSafar/CommerceCore">

**CommerceCore** is an enterprise-oriented modular e-commerce backend designed around **domain boundaries, explicit application use cases, and infrastructure isolation**.

### Architecture

```text
                    ┌─────────────────────┐
                    │      API Layer      │
                    │ ASP.NET Core / REST │
                    └──────────┬──────────┘
                               │
                    ┌──────────▼──────────┐
                    │ Application Layer   │
                    │ CQRS / Use Cases    │
                    └──────────┬──────────┘
                               │
                    ┌──────────▼──────────┐
                    │    Domain Layer     │
                    │ DDD / Aggregates    │
                    └──────────┬──────────┘
                               │
                    ┌──────────▼──────────┐
                    │ Infrastructure Layer│
                    │ PostgreSQL / Redis  │
                    │ Messaging / Cache   │
                    └─────────────────────┘
```

### 🔬 Technical Highlights

* **.NET 10**
* Clean Architecture
* Domain-Driven Design
* CQRS
* Source-generated, zero-reflection mediator
* PostgreSQL
* `ltree` hierarchical category structure
* GiST indexing
* UUIDv7 identifiers
* Transactional Outbox Pattern
* Optimistic concurrency with PostgreSQL `xmin`
* RFC 7807 Problem Details
* Testcontainers integration testing
* **195+ automated tests**

The project is actively evolving with an emphasis on **architecture quality rather than simply feature count**.
