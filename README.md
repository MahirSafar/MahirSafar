### 📌 Featured Architecture & Projects

*   **[CommerceCore](https://github.com/MahirSafar/CommerceCore)** — *Modular E-Commerce Backend (Aug 2026 – Present)*
    *   Enterprise-grade modular monolith built on **.NET 10**, leveraging Clean Architecture, DDD, and CQRS with a source-generated, zero-reflection mediator.
    *   Features hierarchical categories via PostgreSQL `ltree` + GiST indexing, UUIDv7 identifiers, transactional outbox pattern, optimistic concurrency (`xmin`), and RFC 7807 problem details — validated by **195 automated tests** (Testcontainers integration).
*   **[BerryRoasters](https://github.com/MahirSafar/BerryRoasters)** — *Event-Driven Microservices Platform (Jan – Jul 2025)*
