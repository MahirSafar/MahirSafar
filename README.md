### 📌 Featured Projects

**[CommerceCore](https://github.com/MahirSafar/CommerceCore)** — Modular E-Commerce Backend *(solo, Aug 2026–present)*
Enterprise-grade backend on .NET 10 applying Clean Architecture, DDD, and CQRS with a source-generated, zero-reflection mediator. Hierarchical product taxonomies via PostgreSQL `ltree` + GiST indexing, UUIDv7 identities, a versioned JSONB-compiled attribute schema, transactional outbox, optimistic concurrency via `xmin`, and RFC 7807 error responses — backed by 195 automated tests (architecture, domain, and real-Postgres integration via Testcontainers).

**[BerryRoasters](https://github.com/MahirSafar/BerryRoasters)** — Event-Driven Microservices Platform *(solo, Jan–Jul 2025)*
[Backend](https://github.com/MahirSafar/BerryRoasters) · [Frontend](https://github.com/MahirSafar/BerryRoasters-Frontend)
8 business services behind a dedicated Gateway API with a shared cross-cutting library, schema-isolated PostgreSQL, and asynchronous inter-service communication via RabbitMQ. Core 8-service architecture delivered in a focused 35-day build.

**[Dune & Flame](https://duneflame.com/en)** — Live B2C E-Commerce Platform *(professional)*
[Backend](https://github.com/MahirSafar/DuneFlame) · [Frontend](https://github.com/MahirSafar/DuneFlame---Frontend)
Full backend architecture plus a component-based React/Next.js storefront and admin portal — cart, checkout, multi-currency pricing, JWT session handling, and English/Arabic localization. Custom `SlowQueryInterceptor` surfaced 15 slow queries in the first month; an in-memory HybridCache layer cut redundant DB round-trips on high-traffic endpoints by ~40%.
